## 🏗️ Архитектура решения

### Модели данных
```csharp
public class User
{
    public int Id { get; set; }
    public string FullName { get; set; }      // ФИО
    public string Username { get; set; }      // Логин
    public string PasswordHash { get; set; }  // Хеш пароля
    public UserRole Role { get; set; }        // Роль
    public DateTime CreatedAt { get; set; }   // Дата создания
    public bool IsActive { get; set; }        // Статус активности
}
```

### Сервисы
- **UserService**: Авторизация, создание пользователей, хеширование паролей
- **CurrentUser**: Отслеживание текущего пользователя
- **TrainDezhDbContext**: Контекст базы данных с таблицей Users

### UI компоненты
- **LoginWindow**: Окно авторизации
- **UserManagementView**: Управление пользователями
- **MainWindow**: Основное окно с информацией о пользователе

## 🔧 Технические детали

### База данных
- PostgreSQL с Entity Framework Core
- Миграции для создания таблицы Users
