# TrainDezhApp - Приложение для дежурного по станции

## Описание
Desktop приложение на Avalonia UI для управления железнодорожной станцией. Предназначено для дежурных по станции для ведения учета работ, аварий, передачи смен и управления персоналом.

## Технологии
- **UI Framework**: Avalonia 11.0.10
- **Язык**: C# (.NET 8.0)
- **База данных**: PostgreSQL (с Entity Framework Core)
- **Архитектура**: MVVM с ReactiveUI

## Функциональность

### 8 основных модулей:

1. **📊 Дашборд** - Общая сводка и статистика
   - Активные работы
   - Критические аварии
   - Сотрудники на смене
   - Готовность оборудования
   - Последние события

2. **🔧 Работы** - Управление рабочими задачами
   - Список всех работ
   - Приоритеты и статусы
   - Назначение исполнителей
   - Отслеживание прогресса

3. **⚠️ Аварии** - Журнал аварийных ситуаций
   - Регистрация аварий
   - Классификация по серьезности
   - Статус расследования
   - История инцидентов

4. **🔄 Передача смены** - Процедуры смены дежурных
   - Протокол передачи
   - Текущие задачи
   - Важные замечания

5. **👥 Отдел Г** - Управление персоналом
   - Список сотрудников
   - Статусы присутствия
   - Контактная информация

6. **📦 МЗ (Материально-техническое снабжение)**
   - Учет материалов и запчастей
   - Контроль остатков
   - Статусы заказов

7. **📝 Заметки** - Личные заметки дежурного
   - Быстрые записи
   - Важные напоминания

8. **⚙️ Параметры** - Настройки приложения
   - Конфигурация системы
   - Пользовательские настройки

## Дизайн
- Современный Fluent Design
- Темная боковая панель навигации
- Светлая рабочая область
- Цветовая индикация статусов

## Структура проекта
```
TrainDezhApp/
├── Views/           # XAML представления
├── ViewModels/      # Модели представлений (MVVM)
├── Models/          # Модели данных
├── Services/        # Сервисы и бизнес-логика
├── Converters/      # Конвертеры для привязки данных
├── Styles/          # Стили и темы UI
└── Program.cs       # Точка входа приложения
```

## Установка и запуск

### Требования
- .NET 8.0 SDK
- PostgreSQL сервер

### Сборка
```bash
cd TrainDezhApp
dotnet restore
dotnet build
```

### Запуск
```bash
dotnet run
```
