# 🚂 TrainDezhApp - Приложение для управления железнодорожной станцией

Современное desktop приложение на Avalonia UI для управления железнодорожной станцией с полной интеграцией PostgreSQL базы данных, системой авторизации и красивым интерфейсом.

## 🎯 Особенности

- **🔐 Система авторизации**: Полноценная система пользователей с ролями (Администратор/Пользователь)
- **👥 Управление пользователями**: Создание, редактирование пользователей (только для администраторов)
- **🔑 Безопасность**: Хеширование паролей, контроль доступа, валидация данных
- **🎨 Современный UI**: Использует Avalonia UI с Fluent Design
- **📱 9 функциональных вкладок**: Дашборд, Работы, Аварии, Передача смены, Отдел Г, МЗ, Заметки, Пользователи, Параметры
- **🗄️ PostgreSQL интеграция**: Полная поддержка базы данных через Entity Framework Core
- **⚡ CRUD операции**: Создание, чтение, обновление и удаление для всех сущностей
- **🧭 Боковая навигация**: Удобное переключение между разделами
- **📐 Адаптивный дизайн**: Красивые карточки, таблицы и элементы управления
- **🔄 Асинхронные операции**: Все операции с БД выполняются асинхронно
- **🛡️ Fallback данные**: При отсутствии подключения к БД используются тестовые данные

## 🗄️ База данных

### Модели данных
- **User** - Пользователи системы с ролями и авторизацией
- **Work** - Рабочие задания с исполнителями и статусами
- **Accident** - Аварии и инциденты с классификацией серьезности
- **Staff** - Персонал отдела с должностями и статусами
- **Material** - Материально-технические запасы
- **Note** - Заметки с приоритетами
- **ShiftHandover** - Передачи смен между бригадами
- **DatabaseSettings** - Настройки подключения к БД

### Миграции Entity Framework
- `InitialCreate` - Создание базовой структуры таблиц
- `AddTimestampFields` - Добавление временных меток
- `UpdateModelsStructure` - Обновление структуры моделей
- `AddUsersTable` - Добавление таблицы пользователей с авторизацией

### Настройка подключения
```json
{
  "Server": "localhost",
  "Port": 5432,
  "Database": "traindezhdb",
  "Username": "postgres",
  "Password": "your_password"
}
```

## 📱 Функциональные модули

### 1. 📊 Дашборд
- Общая статистика системы из базы данных
- Карточки с ключевыми метриками
- Последние события и уведомления
- Информация об интеграции с PostgreSQL
- Быстрый доступ к важным функциям

### 2. 🔧 Работы
- **CRUD операции**: Создание, редактирование, удаление работ
- **Модель Work**: Title, Description, AssignedTo, Status, Priority, CreatedAt, UpdatedAt
- Отслеживание статуса выполнения
- Назначение исполнителей
- История выполненных работ
- Асинхронные операции с ReactiveCommands

### 3. ⚠️ Аварии
- **CRUD операции**: Полное управление авариями
- **Модель Accident**: Description, Severity, Status, Location, OccurredAt, CreatedAt, UpdatedAt
- Регистрация инцидентов
- Классификация по серьезности
- Отслеживание расследований
- Статистика по авариям

### 4. 🔄 Передача смены
- **Модель ShiftHandover**: ShiftType, OutgoingOfficer, IncomingOfficer, ImportantNotes, IsCompleted
- Оформление смены между бригадами
- Важные заметки для следующей смены
- История передач с временными метками
- Контроль ответственности

### 5. 🏢 Отдел Г
- **Модель Staff**: FirstName, LastName, MiddleName, Position, Status, IsOnShift
- **CRUD операции**: Управление персоналом
- Учет рабочего времени
- Статусы сотрудников (На смене/Не на смене)
- Организационная структура

### 6. 📦 МЗ (Материально-технические запасы)
- **Модель Material**: Name, Description, Quantity, Unit, Status, Location
- **CRUD операции**: Полное управление запасами
- Учет материалов и запчастей
- Контроль остатков
- Заявки на пополнение
- История движения

### 7. 📝 Заметки
- **Модель Note**: Title, Content, Priority, CreatedAt, UpdatedAt
- **CRUD операции**: Создание и управление заметками
- Личные заметки сотрудников
- Важные напоминания
- Категоризация по приоритету (Высокий, Средний, Низкий)
- Поиск и фильтрация

### 8. 👥 Пользователи (только для администраторов)
- **Модель User**: FullName, Username, PasswordHash, Role, CreatedAt, IsActive
- **CRUD операции**: Создание и управление пользователями
- **Автогенерация паролей**: Безопасные пароли с возможностью копирования
- **Роль-основанный доступ**: Видна только администраторам
- **Список пользователей**: DataGrid с информацией о всех пользователях
- **Валидация**: Проверка уникальности логинов

### 9. ⚙️ Параметры
- **Настройки PostgreSQL**: Сервер, порт, база данных, пользователь, пароль
- **Тестирование подключения**: Проверка связи с БД
- **Инициализация БД**: Создание таблиц и seed данных
- **Сохранение настроек**: Персистентное хранение в JSON
- Информация о состоянии базы данных

## 🚀 Установка и запуск

### Требования
- .NET 8.0 SDK или выше
- PostgreSQL 12+ (для работы с базой данных)
- Visual Studio 2022 или JetBrains Rider (рекомендуется)
- Windows 10/11, macOS 10.15+, или Linux

### Клонирование репозитория
```bash
git clone https://github.com/blvck74/train_dezh.git
cd train_dezh/TrainDezhApp
```

### Настройка базы данных
1. Установите PostgreSQL
2. Создайте базу данных `traindezhdb`
3. Настройте подключение в приложении через вкладку "Параметры"
4. Нажмите "Инициализировать БД" для создания таблиц

### Сборка и запуск
```bash
# Восстановление пакетов
dotnet restore

# Установка EF Core tools (если не установлены)
dotnet tool install --global dotnet-ef

# Применение миграций (опционально)
dotnet ef database update

# Сборка проекта
dotnet build

# Запуск приложения
dotnet run
```

### Работа с миграциями
```bash
# Создание новой миграции
dotnet ef migrations add MigrationName

# Применение миграций
dotnet ef database update

# Откат миграции
dotnet ef database update PreviousMigrationName

# Удаление последней миграции
dotnet ef migrations remove
```

### Публикация
```bash
# Создание исполняемого файла для Windows
dotnet publish -c Release -r win-x64 --self-contained

# Создание исполняемого файла для Linux
dotnet publish -c Release -r linux-x64 --self-contained

# Создание исполняемого файла для macOS
dotnet publish -c Release -r osx-x64 --self-contained
```
