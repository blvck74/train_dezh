# Система авторизации TrainDezhApp

## Обзор

TrainDezhApp включает полнофункциональную систему авторизации и управления пользователями с двумя уровнями доступа:
- **Администраторы** - полный доступ ко всем функциям, включая управление пользователями
- **Обычные пользователи** - доступ к основным функциям приложения

## Функциональность

### 🔐 Авторизация
- Окно входа в систему при запуске приложения
- Проверка логина и пароля
- Хеширование паролей с использованием SHA256
- Защита от неавторизованного доступа

### 👥 Управление пользователями (только для администраторов)
- Создание новых пользователей
- Автоматическая генерация паролей
- Назначение ролей (Администратор/Пользователь)
- Просмотр списка всех пользователей
- Копирование учетных данных в буфер обмена

### 🎯 Контроль доступа
- Роль-основанная навигация
- Скрытие функций управления пользователями от обычных пользователей
- Отображение информации о текущем пользователе

## Учетная запись по умолчанию

При первом запуске создается администратор:
- **Логин:** `root`
- **Пароль:** `admin123`
- **Роль:** Администратор

## Архитектура

### Модели данных
```csharp
public class User
{
    public int Id { get; set; }
    public string FullName { get; set; }
    public string Username { get; set; }
    public string PasswordHash { get; set; }
    public UserRole Role { get; set; }
    public DateTime CreatedAt { get; set; }
    public bool IsActive { get; set; }
}

public enum UserRole
{
    User,
    Administrator
}
```

### Сервисы
- **UserService** - управление пользователями и авторизация
- **CurrentUser** - отслеживание текущего авторизованного пользователя

### UI компоненты
- **LoginWindow** - окно авторизации
- **UserManagementView** - управление пользователями
- **MainWindow** - основное окно с информацией о пользователе

## Безопасность

- Пароли хешируются с использованием SHA256
- Проверка уникальности имен пользователей
- Валидация входных данных
- Защита от SQL-инъекций через Entity Framework

## База данных

Система использует PostgreSQL с миграциями Entity Framework:
- Таблица `Users` с индексом уникальности на поле `Username`
- Автоматическое создание администратора при инициализации

## Тестирование

Включены unit-тесты для:
- Авторизации пользователей
- Создания новых пользователей
- Хеширования и проверки паролей
- Валидации данных

Запуск тестов:
```bash
cd TrainDezhApp.Tests
dotnet test
```

## Демонстрация

Для демонстрации функциональности запустите:
```bash
cd TrainDezhApp.Demo
dotnet run
```

## Использование

1. **Запуск приложения** - появляется окно авторизации
2. **Вход в систему** - введите логин и пароль
3. **Управление пользователями** (администраторы):
   - Перейдите на вкладку "Пользователи"
   - Нажмите "Добавить пользователя"
   - Заполните данные и выберите роль
   - Скопируйте сгенерированные учетные данные
4. **Информация о пользователе** - отображается в левом нижнем углу

## Технические детали

- **Framework:** .NET 8.0
- **UI:** Avalonia 11.3.0
- **База данных:** PostgreSQL с Entity Framework Core
- **Тестирование:** xUnit
- **Архитектура:** MVVM с ReactiveUI
